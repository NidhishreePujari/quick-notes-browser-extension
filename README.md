# Quick Notes Browser Extension

A beginner-friendly Google Chrome extension that lets users save a short note locally in their browser.

## Features

- Save a short note.
- Retrieve the saved note when the popup is reopened.
- Clear the saved note.
- No account or external server is required.

## Installation for Testing

1. Download or clone this repository.
2. Open Google Chrome and visit `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the `QuickNotesExtension` folder.
5. Click the Quick Notes extension icon to use it.

## Technologies Used

- HTML
- CSS
- JavaScript
- Chrome Extensions Manifest V3
- `chrome.storage.local`

## Privacy

Notes are stored locally using Chrome extension storage. Do not store passwords or other sensitive information in this demonstration extension.
